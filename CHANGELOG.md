# Changelog

All notable changes to VendEdge Contracts will be documented here.

## 0.1.0 — initial development version

- Add protocol version 1 message types for heartbeat, telemetry, stock reports, and dispense results.
- Add runtime validation with field-specific issues and boundary checks.
- Add Node.js test suite and GitHub Actions CI for Node.js 20 and 22.
- Add usage examples, security boundaries, and contribution guidance.

This is an initial development version. Compatibility and numeric ranges should be reviewed with real consumers before a stable 1.0 release.
